## Agent Skill

Install the Timescope skill for your coding agent:

```bash
npx skills add xenodrive/timescope
```

The [skill](skills/timescope/SKILL.md) maps implementation tasks to Timescope APIs,
with timepicker and chart examples, integration guidance, and documentation links.
