# Advanced

Use these guides when integrating Timescope into an application. They build on [Core Concepts](/guide/concepts) with configuration choices and practical API usage.

| What do you want to do?                                            | Guide                                             |
| ------------------------------------------------------------------ | ------------------------------------------------- |
| Add a chart to a framework application and synchronize its state   | [Framework Bindings](/guide/advanced/frameworks)  |
| Load a large dataset, refresh changed data, or append live samples | [Loading and Updating Data](/guide/advanced/data) |
| Change configuration, navigate, or wait for a complete view        | [Controlling Views](/guide/advanced/views)        |
| Choose browser rendering options or generate an image in Node.js   | [Rendering Backends](/guide/advanced/backends)    |

The framework guide explains the shared component rules. Its [Vue](/guide/advanced/frameworks/vue), [React](/guide/advanced/frameworks/react), [Svelte](/guide/advanced/frameworks/svelte), [Solid](/guide/advanced/frameworks/solid), and [Luna](/guide/advanced/frameworks/luna) pages show the chart alongside framework-specific code.

For chart appearance, explore the [Examples](/guide/examples/) and [Playground](/guide/examples/playground). For complete option and method signatures, use the [API Reference](/api/timescope).
