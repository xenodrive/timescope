# Advanced

Choose a topic for what you want to build. These guides can be read independently:

- [Styling](./styling) — customize the appearance and compose your own Charts with Marks and Links.
- [Chunk Loading](./chunk-loading) — explore large histories by loading data for the current time range and resolution.
- [Live Streaming](./live-streaming) — append incoming samples and follow a live or playback clock.
- [Running on Node.js](./running-on-node) — share chart configuration and data loaders between the browser and server.

For snapshot data, chart presets, multiple Series, Tracks, and decimation, see [Drawing a Chart](/guide/drawing-a-chart). Browse the [Gallery](/examples/gallery) to see the drawing and data-loading features in action.
