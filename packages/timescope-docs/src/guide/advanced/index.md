# Advanced

After Drawing a Chart, choose the workflows your application needs: remote history and live data, playback and view updates, or image exports. These guides are independent; shared concepts are covered in [Core Concepts](/guide/concepts).

| Topic                                                        | Guide                                             |
| ------------------------------------------------------------ | ------------------------------------------------- |
| Snapshot loading, chunk loading, refreshes, and live appends | [Loading and Updating Data](/guide/advanced/data) |
| Playback clocks, runtime configuration, and prepared views   | [Controlling Views](/guide/advanced/views)        |
| Rendering environments, PNG exports, and custom fonts        | [Rendering Backends](/guide/advanced/backends)    |
| Backgrounds, chart colors, and dark/light themes             | [Styling](/guide/advanced/styling)                |
